# Documentation Archive

This directory contains historical documentation for completed work items, implementation reports, and deprecated guides.

## Purpose

Documents are archived here when:
- Implementation work is complete and merged
- The document served as a planning/implementation guide but is no longer actively needed
- Historical context is valuable but shouldn't clutter active documentation
- The information is superseded by code, tests, or updated documentation

## Contents

- [**Q400 Integration and DataStore Fixes**](q400_integration_and_datastore_fixes.md) - Implementation report from November 2025 covering Q400 dataset integration and critical DataStore bug fixes

## Using Archived Documents

Archived documents are useful for:
- Understanding historical context and design decisions
- Reviewing how specific features were implemented
- Learning from past integration experiences
- Troubleshooting issues related to completed work

## Archive Policy

Documents should be archived (not deleted) when:
- They contain valuable implementation details or lessons learned
- They document significant bugs and their fixes
- They provide context that may be needed in the future
- They represent substantial work that should be preserved

Documents may be deleted if:
- Content is fully superseded by current documentation
- Information is outdated and potentially misleading
- No historical value for future reference
