# Research and Planning Documentation

This directory contains research documents, model proposals, and planning materials for future AirTrace development.

## Contents

- [**Model Proposals**](model_proposals.md) - Comprehensive proposals for adding new models to AirTrace based on recent literature (2023-2025)

## Purpose

Documents in this directory are:
- **Research-oriented**: Literature reviews, model surveys, architecture comparisons
- **Forward-looking**: Proposals for future implementations, not current features
- **Planning materials**: Implementation roadmaps, priority assessments, effort estimates

These are distinct from user-facing documentation in the main `/docs` folder, which describes current functionality.

## Using Research Documents

Research documents are useful for:
- Planning which models to implement next
- Understanding the landscape of time series forecasting architectures
- Evaluating trade-offs between different approaches
- Estimating implementation effort for new features

## Contributing Research

When adding research documents:
1. Focus on actionable proposals with clear implementation paths
2. Include references to papers, code repositories, and benchmarks
3. Provide effort estimates and priority assessments
4. Update this README with new entries
